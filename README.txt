Grumpy Shark Website 🦈
A vibrant, accessible, and ocean-inspired website that brings Grumpy Shark’s adventures to life. Designed for interactivity, inclusive storytelling, and smooth navigation across all devices.
🌊 Project Overview
This project is a multipage Flask web app featuring:
- Three illustrated children’s books, each with its own preview page
- Custom HTML/CSS layout with responsive design
- Voice narration and color contrast enhancements for accessibility (WCAG 2.1 AA compliant)
- Semantic HTML and proper heading hierarchy
- A dedicated contact link for purchase inquiries
🚀 Features
- Preview pages with individual sample spreads
- Character bios and author intro sections
- “Coming Soon” notices for unpublished books
- Centered content with readable layout for all screen sizes
- Styled with flexible, mobile-first CSS and hover overlays
🧩 Tech Stack
- Python 3 & Flask
- HTML5 / CSS3
- Jinja2 Templates
- Static assets served from /static/books
