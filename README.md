# 🦈 Grumpy Shark Adventures

**An accessible, voice-narrated, and visually engaging web experience that brings storytelling to life.**  
Created with HTML, CSS, JavaScript, and Flask — fully responsive, WCAG 2.1 AA compliant, and narrated by browser-native speech synthesis.

---

## 🌟 Features

- 🎙️ **Narration on Every Page:** Accessible speech synthesis for users with visual or cognitive needs  
- 🎨 **Responsive Layout:** Clean, colorful design adapted for all screen sizes  
- 🧠 **Accessible Design:** Passes all WCAG 2.1 AA checks (contrast, structure, navigation)  
- 🗺️ **Dynamic Routing:** Flask powers consistent navigation and server-side page rendering  
- 🎈 **Animations & Styling:** Glowing buttons, hover effects, and personality-rich CSS

---

## 📂 Technologies Used

- HTML5, CSS3, JavaScript  
- Flask (Python-based framework)  
- GitHub Pages (deployment)  
- WCAG Tools (for accessibility auditing)
